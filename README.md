This is the new version of the FrontendForms module which could be downloaded for testing purposes. It is planned to replace this version with the default FrontendForms module after it has been tested carefully.

Please do not use this version on live-sites at the moment!!

To test this version do the following steps:

1. Download the ZIP from GitHub and unzip it on your computer
2. Rename the unzipped version from FrontendForms3_main to FrontendForms
3. Copy the folder to your site folder and click the module refresh button (if you the default version of FrontendForms installed, then the migrate script should run and update all files to the latest version and remove all orphaned files from the old version
4. Start trying and testing the new module version
5. Report any bugs or issues directly here on GitHub
